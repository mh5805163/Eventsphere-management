# Asset sources

Bundled event photography comes from Unsplash. Images are used as visual demonstration content and do not identify the fictional sample companies or events.

- `photo-1519225421980-715cb0215aed.jpg` — wedding table styling
- `photo-1478146896981-b80fe463b330.jpg` — celebration table details
- `photo-1519741497674-611481863552.jpg` — floral wedding setting
- `photo-1530103862676-de8c9debad1d.jpg` — celebration decor
- `photo-1511578314322-379afb476865.jpg` — event gathering
- `photo-1416879595882-3373a0480b5b.jpg` — plants and sustainable living
- `photo-1515187029135-18ee286d815b.jpg` — professional gathering

Original image URLs use `https://images.unsplash.com/<photo-id>`. The downloaded files are in `public/images` and require no remote image loading.

Cormorant Garamond and DM Sans are bundled from Google Fonts. The respective SIL Open Font License texts are included in `public/fonts`. Icons use Lucide React. Components use Radix primitives, class-variance-authority, and shadcn-style composition; charts use Recharts. Dependency versions are locked in `package-lock.json`.
